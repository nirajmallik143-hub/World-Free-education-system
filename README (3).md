# Sikshya Global AI - World Free Education System (7G Quantum Edition)

Welcome to the official repository of **Sikshya Global AI**, a decentralized, client-side educational platform built to bring free universal education to humanity under the MIT License.

## 🚀 Features
- **Quantum Biometric Neuro-Engine v7.5**: Interactive coaching and problem-solving modules.
- **Multilingual Support**: Tailored for Nepal CDC (Grades 1-12 & SEE) and global curricula.
- **Offline & Local Ready**: Runs entirely client-side without strict external API keys.
- **Termux & Mobile Compatible**: Easily cloned, served, and run locally on Android via Python or Node.

## 🛠️ Quick Local Setup (Termux)
```bash
git clone https://github.com/nirajmallik143-hub/World-Free-education-system.git
cd World-Free-education-system
python3 -m http.server 8080
```
Then open `http://localhost:8080` in your mobile browser.
